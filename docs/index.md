# Q-Selector

Q-Selector ranks quantum backends for OpenQASM 2 circuits using a random forest
trained on circuit structure and backend calibration features. It supports local
model training, batch recommendations, and evaluation against simulated measurements.

The bundled dataset covers 578 circuits and 20 backend profiles. Start with
[Installation](installation.md) and the [Usage guide](quickstart.md).
